**Aesthetic name:** Sunlit blotter correspondence — cream letter sheet, iron-gall ink, terracotta wax.

**Top-studio bar:** Imagine Pentagram / Collins executing an epistolary form tool — one calm sheet, no marketing chrome, type that feels written not “designed,” motion like turning a page.

**Biggest gaps vs that studio (and vs Youform fill):**
1. Desk list still “admin table” — not a tray of letters.
2. Paper fiber underlay was too loud in early R1 (softened).
3. Intro still shows sample-title brackets `[SAMPLE]` — product voice leak.
4. Youform fill wins on full-bleed question focus; ours is sheet-in-frame (intentional) but density of chrome above the fold (seal dots + progress + kicker) competes with the question.
5. No video/keyframe letter-turn yet at critic time (added Tech 5 CSS page-turn + seal-press).

**Score vs studio bar:** **5.2/10** (up from honest 3.8 baseline). Original Youform fill still preferred for one-question focus in blind A/B; candidate preferred for craft/anti-slop once texture softened.
